## 撮影カウントダウンの仕組み（重要）
以前は「1枚目、いくよー！3、2、1、はい！」を1本の音声にしていましたが、前置きの長さが毎回違うため
画面の「3・2・1・ハイ！」表示とズレる問題がありました。そのため **前置き（`intro_shotN`）と
「3」「2」「1」「はい！」（`count_3`〜`count_hai`）を別ファイルに分割** し、コード側は
各音声の再生完了（`ended`イベント）を待ってから次の数字を表示する方式に変更しています。
これにより、音声の長さがどう変わっても表示とボイスは自動的にズレなくなります。
録音し直すときも `SOUND_DURATION` のような秒数調整は一切不要で、ファイルを差し替えるだけでOKです。
`count_3`〜`count_hai` は4回の撮影すべてで共通利用しているので、1セット録るだけで済みます。

## 録音時の注意
- 各ファイルはセリフ単体のみ。現在の音源は ffmpeg で **前後の無音カット＋ラウドネス正規化
  （loudnorm I=-16）** を適用済みです。録音し直した場合も同じ処理をかけると音量が揃います：
  `ffmpeg -i in.mp3 -af "silenceremove=start_periods=1:start_threshold=-45dB:start_silence=0.05,areverse,silenceremove=start_periods=1:start_threshold=-45dB:start_silence=0.08,areverse,loudnorm=I=-16:TP=-1.5:LRA=11,alimiter=limit=0.95" out.mp3`
- 特にカウントダウン（count_3〜count_hai）は無音を詰めるほど実機らしいテンポになります
  （表示側が音声の終わりに追従するので、長さ調整は不要です）。
- ファイル形式はmp3のまま同名で上書きすれば差し替え完了です。

### 結線するときの注意（音羽 → 工藤）

1. **案内ボイスは `playAnnounce()` を通す。** `playSound()` で鳴らすと、この27本は
   既存の案内ボイスと重なる。`playAnnounce` は1本チャンネルで前の案内を必ず止める。
2. **「◯◯のあとに続けて」と書いた組は `queueAnnounce()` で繋ぐ。**
   `playAnnounce` を2回続けて呼ぶと1本目が即座に切れる。
   例: `playAnnounce('decoStart'); queueAnnounce(() => playAnnounce('heiseiDecoPhotoSwitch'), soundDurationMs('decoStart') + 250);`
3. **初回だけ鳴らす系（korokoro / ugokasu / beautyParts）はフラグで1回に絞る。**
   道具を持ち替えるたびに喋ると3分の落書きタイムが説明で埋まる。
   フラグは `#btn-restart`（もう一回あそぶ）でリセットする。
4. **`SOUND_FILES` に追加しないと `soundAvailable` の未着スキップが効かない。**
   キー名は `heisei_deco_gate` → `heiseiDecoGate` のようにキャメルケースで。
   `sw.js` のプリキャッシュ一覧にも27本を足すこと（足さないとオフライン時だけ無音になる）。
5. **`ok_check.mp3` が結線漏れしている**（2026-08-14 音羽が発見）。8/12に納品した13本のうち
   これだけ `SOUND_FILES` にも `sw.js` にも入っていない。撮影直後の確認（「この画像でオッケー？！」）で
   鳴らす想定のファイルなので、今回の結線のついでに拾ってほしい。

## 音声の全面作り直し（2026-08-23・音羽）— 令和の型／太子祭プリ／音量調整

きっかけはオーナーの問い「**令和だからって本当に落ち着いているのか？？？**」と、
それを受けた柄本の実機調査（`starter-office/data/work/reiwa-voice-tone-20260823.md`）。

**結論の要点**: 「令和＝落ち着いている」は半分誤り。現行機の公式コンセプトはむしろ
「テンションMAX」「ノリまで写せる」。変わったのは**テンションの高低ではなく、
機械が客に指示する量**だった。よって令和の声は「静かな声」ではなく
**「短く・少なく・押しつけない声」**として作り直した。**直したのはトーンではなく原稿。**

| | 平成モード | 令和モード |
|---|---|---|
| 機械の立場 | 仕切り役（号令・煽り） | 裏方（合図・案内） |
| 指示の量 | 多い（ポーズ・変顔・ジャンプまで指定） | 少ない（見本は画面に任せ、声では指定しない） |
| 文末 | 「！」の連発・語尾上げ | 「。」で落とす。「！」は1画面に1回まで |

### 生成パラメータ（2026-08-23 改訂）

- 平成用: edge-tts `ja-JP-NanamiNeural` **rate +18% / pitch +25Hz**（変更なし）
- 令和用: 同話者 **rate +6% / pitch +14Hz**（**pitch を +10Hz から +14Hz へ戻した**）
  - 理由: 文化祭のガヤ・スピーカー越しで +10Hz は沈む恐れがある（柄本の指摘）。
    **落ち着きは音量やピッチで作らない。語彙とテンポで作る。**
  - これに伴い **8/14の `reiwa_*` 13本も +14Hz で録り直した**（原稿は1文字も変えていない）。
    混在させると `reiwa_deco_start → reiwa_deco_photo_switch` のような連結の途中で
    声の高さが段になるため。**令和31本は全部おなじ声・おなじ設定。**

### 後処理（2026-08-23 改訂・従来より正確になった）

前後無音カット → **ループ実測ラウドネス** → 一定ゲインで I=-16 LUFS → リミッター → mp3(48kHz/mono/64k)

```
# ① 前後の無音カット（従来どおり）
ffmpeg -i in.mp3 -af "silenceremove=start_periods=1:start_threshold=-45dB:start_silence=0.05,areverse,silenceremove=start_periods=1:start_threshold=-45dB:start_silence=0.08,areverse" -ar 48000 -ac 1 trimmed.wav
# ② ラウドネスを測る。⚠️ 0.4秒未満のクリップは、6秒以上になるまでループしてから測ること
#    （そのまま測ると -70.0 LUFS と出る。これは「無音」ではなく「測れていない」の意味）
ffmpeg -stream_loop N -i trimmed.wav -af loudnorm=I=-16:TP=-1.5:LRA=11:print_format=json -f null -
# ③ 測った値との差ぶんだけ一定ゲインを掛けて、リミッターで蓋をする
ffmpeg -i trimmed.wav -af "volume=<-16.0 - 実測値>dB,alimiter=level=disabled:limit=0.95" -ar 48000 -ac 1 -c:a libmp3lame -b:a 64k out.mp3
# ④ 仕上がりをもう一度②で測り、-16.0 から 0.15dB 以上ずれていたらゲインを直して撃ち直す
```

🚨 **`alimiter` の `level`（auto level）は既定が true で、出力を limit まで持ち上げ直す。**
ラウドネスを狙って揃える用途では **必ず `level=disabled` を付ける**。
これを知らずに `alimiter=limit=0.841` を使うと、狙いより +1.5dB ほど大きく仕上がる。

### 追い直し: 平成の語彙の年代直し（2026-08-23 第2便・柄本の判定を受けて2本）

音羽が挙げた4件を柄本が判定した結果（`starter-office/data/articles/era-designer-20260823-heisei-goi.json`）、
**録り直しが必要なのは2本だけ**だった。残り2件は「触らない」判定（理由は上の注2・注4に書いた）。

| ファイル | 前 | 後 | 理由 |
|---|---|---|---|
| `attract_call.mp3` | 太子祭プリ 撮ってこ〜！**めっちゃ盛れるよ〜！** | 太子祭プリ 撮ってこ〜！**超かわいく写るよ〜！** | **年代ずれ（考証の誤り）** |
| `09_time_warning.mp3` | あと10秒！**お急ぎください！** | **あと10秒〜！ラストスパート！** | **テンポ（考証ではなく演出）** |

- **`attract_call`**: 「盛る・盛れる」は **2009年の女子中高生ケータイ流行語大賞・年間大賞**
  （元は2005-06年頃からの「盛り髪」由来）。平成モードの設定年代 **1999〜2003年とは6〜10年ずれる**。
  「アゲアゲ」(2007)・「チョベリグ」(1996) の数年ゆらぎとは桁が違う、というのが柄本の判定。
  差し替えた「**超**」は **1996年「チョベリバ」で裏が取れる**（確度強）ので年代内。
  拍数がほぼ同じなので呼び込みのテンポも変わっていない。
  ※「めっちゃ」は全国区化の時期が特定できず**確度=要検証**。今回は残していない
  （「超」に寄せたため）が、致命的ではないという判定だった。
- **`09_time_warning`**: 考証の誤りではない（敬語混じりが当時なかったという証拠は無い）。
  理由は**演出**で、平成の型は「短い掛け声の連発」なのに「お急ぎください」は6モーラで重く、
  `doodle_halftime`「いそげいそげ〜！」より**急かす度合いが下がって聞こえる＝逆効果**だったため。
  → **令和版 `reiwa_time_warning.mp3`「あと10秒。」はこの直しの対象外。触らないこと**
    （令和は「事実を言うだけ」が型で、急かさないのが正解）。

読みは実測で確認済み: 「超」→ **ちょう**、「写る」→ **うつる**
（同文の仮名版との音響距離: 対照 0.10 ／ ちょうかわいくうつる 0.41 ／ こえるかわいくうつる 0.49）。
仕上がり: `attract_call` 3.37秒 **-15.9 LUFS / -2.3 dBTP** ／
`09_time_warning` 2.47秒 **-15.9 LUFS / -2.2 dBTP**（どちらも基準内）。
